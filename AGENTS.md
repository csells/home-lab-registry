# Working on this registry

Keep real inventory, credentials and runtime state out of source control. Develop in a disposable VM with its own runtime. Exercise actual browser interactions before claiming UI changes work. Production promotion requires explicit operator approval. Keep records in the registry and procedures in the home-lab skill. Verify backups and rollback before deployment.

For lab-wide direction, read `specs/vision/home-lab.md`; for implemented boundaries,
read `specs/architecture/current.md`. Keep proposed work in numbered `specs/plans/`
documents and update the architecture when that work is implemented and verified.
